## 🌐 What is a Website?

A website is a collection of related web pages and resources that are accessible through the Internet using a web browser.

A website can contain:

- Text
- Images
- Videos
- Forms
- Links
- Navigation menus
- Interactive elements
- Documents and other resources

Websites are hosted on web servers and can be accessed using a unique web address called a **URL (Uniform Resource Locator)**.

---

## 🧩 Components of a Website

A website consists of several important components that work together to provide a complete user experience.

### 🖥️ Web Pages

Web pages contain the actual content displayed to users and are commonly created using HTML.

### 🎨 Design

CSS is used to control the visual appearance of a website, including:

- Colors
- Fonts
- Spacing
- Layouts
- Buttons
- Cards
- Navigation menus
- Responsive designs

### 🧭 Navigation

Navigation allows users to move between different pages and sections of a website.

Common navigation elements include:

- Navigation bars
- Menus
- Links
- Buttons
- Breadcrumbs

### 📄 Content

Content is the information presented on a website, such as text, images, videos, forms, and other resources.

### 🌍 Web Hosting

Web hosting provides the server environment where website files are stored and made accessible through the Internet.

### 🔗 URL

A URL is the address used to access a website or a particular resource on the web.

## 🔄 How a Website Works

A simplified website request process is:

**User → Browser → Internet → Web Server → Website Files → Browser → User**

When a user enters a URL:

1. The browser sends a request to the web server.
2. The server receives the request.
3. The server finds the requested resources.
4. The server sends the resources back to the browser.
5. The browser processes the files.
6. The website is displayed to the user.

**Planning → Structure → Design → Functionality → Testing → Deployment**

### Functionality

Adding interactions and dynamic behavior using JavaScript when required.

### Testing

Testing the website across different browsers, screen sizes, and devices.

### Deployment

Making the completed website available online through a hosting service.

# OVERVIEW OF A WEBSITE:

- A website is a collection of web pages written in HTML. 

- To make it accessible worldwide, it must be stored on a computer connected to the Internet 24/7.

- These computers are called web servers.

- The website's web pages are linked with hyperlinks and hypertext and share a common interface and design.

- The website might also contain some additional documents and files, such as images, videos, or other.



COMPONENTS OF A WEBSITE:

We know that a website is a collection of a webpages hosted on a web-server. 

These are the components for making a website.

- Webhost: Hosting is the physical location where a website lives. 
         A group of linked webpages becomes a website only when hosted on a web server. 
         The web server stores these files and sends them to users when they enter the website’s address.

- Address: A website’s address is its URL. When a user enters this URL into a browser, 
         the web server receives the request and delivers the requested website.

- Homepage : The home page is the first webpage a visitor sees. 
           It sets the look and feel of the website and guides users to the rest of its pages.

- Design : It is the final and overall look and feel of the website that has a result of 
         proper use and integration elements like navigation menus, graphics, layout, navigation menus etc.

- Content : Every web pages contained on the website together make up the content of the website. 
          Good content on the webpages makes the website more effective and attractive.

- The Navigation Structure: The navigation structure of a website is the order of the pages, the collection of what links to what. 
                          Usually, it is held together by at least one navigation menu.



HOW TO ACCESS WEBSITES?

To access a website:

- A user enters the website’s URL into a browser’s search bar.

- The browser sends a request to the web server.

- The web server delivers the requested web page and its content to the browser.

- The delivery process varies depending on whether the website is static or dynamic.
